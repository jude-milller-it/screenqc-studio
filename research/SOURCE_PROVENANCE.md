# Legacy source preserved

This folder contains the source files included in the user's uploaded `DeepLabV3_source_for_refactor.zip`, copied with the same relative paths. Model weights and large images were excluded from the uploaded archive; no substitute checkpoints are provided. New CLI/adapters/GUI live at the root, outside this folder, to avoid modifying the original training and network implementations.

When running the old training or ablation scripts from this folder, their original paths and weight assumptions still apply.
